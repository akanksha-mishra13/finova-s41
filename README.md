##  What is Finova?

**Finova** is an AI-powered financial health and decision-support platform built for **Smart India Hackathon Problem Statement 41**.

Most financial applications tell users **what happened to their money**.

Finova goes one step further.

It helps users understand:

* Where they currently stand financially
* Why their financial health looks the way it does
* What they can improve
* How a financial decision could affect their future
* Which alternatives may be better
* What actions they can take next

### Our core idea:

```text
             FINANCIAL DATA
```

# 🔐 Responsible AI & Financial Safety

Finova is designed as a financial education and decision-support platform.

The system:

* Does not guarantee investment returns
* Does not invent user financial data
* Clearly identifies missing information
* Explains calculations where appropriate
* Encourages verification for important financial decisions
* Does not present itself as a bank
* Does not replace professional financial advice

The objective is to **empower users**, not make financial decisions on their behalf.

# ⚡ Getting Started

## Clone the repository

```bash
git clone <your-repository-url>
cd finova-s41
```

## Install frontend dependencies

```bash
cd frontend
npm install
```

## Start frontend

```bash
npm run dev
```

## Install backend dependencies

```bash
cd backend
npm install
```

## Start backend

```bash
npm run dev
```

# 🔑 Environment Variables

Create the required environment configuration files for the frontend and backend.

Example:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_APP_ID=your_app_id
```

Never commit private credentials, service-account files, or secret API keys to GitHub.
